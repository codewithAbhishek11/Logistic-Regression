## What is Logistic Regression?

Logistic Regression is a **classification algorithm** used when the **target variable is categorical**.

Instead of predicting continuous values like Linear Regression, Logistic Regression predicts the **probability that a data point belongs to a particular class**.

The probability is calculated using the **Sigmoid Function**.

---

## Sigmoid Function

The Sigmoid function converts any real value into a number between **0 and 1**.

> σ(z) = 1 / (1 + e^(-z))
